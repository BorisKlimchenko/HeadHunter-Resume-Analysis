# Исследование зависимостей в данных: Разведывательный анализ (EDA) датасета HeadHunter

## 1. Описание проекта
Данный проект представляет собой полноценный цикл разведывательного анализа данных (EDA) на основе реального датасета резюме с платформы HeadHunter. Цель проекта — подготовка сырого массива данных для машинного обучения. Анализ вскрывает скрытые зависимости, устраняет структурные аномалии и гарантирует математическую адекватность признаков.

## 2. Архитектура и методология очистки данных
Трансформация данных опирается на принципы оборонительного программирования (Defensive Programming) и безопасного управления состояниями (State Isolation):
* **Дедупликация:** Избыточная детализация времени маскировала идентичные записи и потребовала принудительного отсечения часов и минут.
* **Работа с пропусками:** Алгоритм использует дифференцированный подход. Строки с дефектными категориальными признаками (должность, место работы) удалялись безвозвратно. Числовые пустоты (опыт работы) получили заполнение робастной медианой для защиты от статистического смещения.
* **Cross-feature валидация:** Векторная валидация признаков помогла найти логические парадоксы (опыт работы превышает физический возраст). 
* **Ликвидация статистических выбросов:** Логические маски с последующей инверсией (`~`) отфильтровали финансовые аномалии. Итоговая фильтрация завершается вызовом метода `.copy()`. Этот шаг создает независимый клон DataFrame и предотвращает конфликты ссылок (SettingWithCopyWarning). Процесс также включает логарифмическую трансформацию и асимметричный метод Z-отклонений (от -3 до +4 сигм) для сохранения хвоста опытных возрастных кандидатов.

## 3. Визуализация и выводы
Проект содержит 11 интерактивных графиков Plotly. Из-за ограничений GitHub на рендеринг Plotly MIME-данных, код физически экспортирует все графические артефакты в формате HTML. Файлы доступны для интерактивного просмотра в директории `images/`. Тексты с аналитическими выводами располагаются в Markdown-ячейках непосредственно под каждым графиком.
